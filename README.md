# Clinic Database

Мой учебный проект по SQL. Учусь на нём писать запросы и проверять данные, как тестировщик.

База данных платной больницы со стационаром (PostgreSQL).

## Что внутри
- отделения, врачи, пациенты
- приёмы
- палаты
- госпитализации

## Папки
- `database` — схема и тестовые данные
- `queries` — мои SQL-запросы
- `test-cases` — проверки данных
- `documentation` — описание проекта

Проект растёт вместе со мной, буду добавлять новое.
